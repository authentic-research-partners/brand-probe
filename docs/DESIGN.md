# Audit workspace design

An instrument for reviewing experiments: a narrow navy navigation column, an open white work surface, and an evidence table with expandable answers. The prompt list is the main working object, not decorative metric cards.

Palette: navy #16324f, ink #23384d, blue #225fc7, pale blue #edf3fa, white #ffffff, warning brown #805516. Typography: Avenir Next for interface text with system fallbacks; Georgia for the single page title. Layout: left-aligned setup, then cost review, then results. Avoid oversized hero metrics; counts appear beside their denominators.

Desktop: navigation | audit configuration and prompt editor; results occupy the full workspace width. Mobile: navigation becomes a top bar and forms become one column. Visible labels, focus rings, keyboard-operable disclosure controls, no required motion. All model text renders as text, never executable markup.

Review: the evidence table and editable questions suit an audit tool; the sidebar is secondary. Keep synthetic demo labeling visible throughout. Do not imply that sample responses are actual observations about SoTS.
